# nmi-notes v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tray-resident Windows note app with five global hotkeys, SQLite storage, flux-style store, editor and list windows.

**Architecture:** One UI thread owns the Store (pure Rust, returns `Change` events) and all Win32 windows; a writer thread owns SQLite. Window procedures never touch app state directly — they `post(Action)` into a queue drained by `App` whenever it is not already borrowed (re-entrancy safe).

**Tech Stack:** Rust stable (MSVC), `windows` 0.62, `rusqlite` 0.32 (bundled), `serde` + `toml` 1.x, `proptest` (dev).

> Note: executed inline in the same session at the user's request ("build it"). Tasks specify files, interfaces, and test cases; code is written during execution.

## Global Constraints

- Windows 10/11 only; per-monitor DPI v2; common controls v6 via embedded manifest.
- Store text uses `\n` only; `Edit`/`Splice` offsets are UTF-16 code units.
- DB: `%LOCALAPPDATA%\nmi-notes\notes.db`, WAL, `synchronous=NORMAL`.
- Config: `%APPDATA%\nmi-notes\config.toml`.
- Default hotkeys: `Win+Alt+N/A/S/C/L`.
- Window offset from pointer: 200 px (DPI-scaled), left preferred.
- Editor debounce: 250 ms. Toast visible ~1.5 s.
- Never silently lose a note.
